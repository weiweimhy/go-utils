当检测到生成的 `implementation_plan.md` 或 `task.md` 包含英文内容时，必须将其翻译为中文。

## 翻译准则

1. **术语保持**：专有名词（如 Git、Go、JWT、RESTful 等）保持原样。
2. **结构一致**：翻译后的文档结构、Markdown 格式、链接地址和代码块必须与原文档完全一致。
3. **语言风格**：使用专业、简洁的中文技术术语，符合中文阅读习惯。
4. **覆盖范围**：
   - 标题、段落、列表项、任务描述。
   - 警告（Alerts）和提示信息。
   - 变更说明。

## 翻译流程

1. **读取内容**：读取需要翻译的 `.md` 文件。
2. **执行翻译**：将所有非代码、非链接、非术语的文本内容翻译为准确的中文。
3. **覆盖写入**：将翻译后的内容写回原文件。
