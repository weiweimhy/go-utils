# Go 开发规则入口（Go Entry · L1）

> 本项目是一个 **Go 通用封装库 / 工具集**。
>
> 本文件是 **所有 Go 相关工作的唯一入口规则**。
> 在编写、生成、修改任何 Go 代码之前，**必须先理解本文件**。

---

## 一、项目定位与设计哲学

### 核心定位

* 本项目是：
  * **高度封装的工具套件**：简化常用中间件和逻辑的操作。
  * **一致性的 API 设计**：确保不同模块间具有相同的调用体感。

### 设计哲学

* **简洁性**：API 应当直观，减少调用方的代码模板。
* **安全性**：默认包含最佳实践（如并发安全、资源自动回收）。
* **高性能**：底层采用高性能依赖（如 zap, sonic）。

## 三、开发核心约束（不可违背）

* **禁止引入 UI 相关逻辑**：本项目是纯粹的逻辑库。
* **避免过度抽象**：优先保证 API 的可读性。
* **高性能优先**：在关键路径上必须遵守性能优化规则。

---

## 四、违规处理原则

* 未遵守本入口文件的代码：
  → 视为不合规，拒绝合并。

* 违反库设计原则或 Go 工程铁律的实现：
  → **必须重写**。
