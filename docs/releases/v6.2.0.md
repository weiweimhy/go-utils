# v6.2.0（2026-10-13）

本次发布新增轻量的 PostgreSQL 子模块，并统一升级根模块、扩展模块及 CI 的 Go 版本。

## 升级要求

- **最低 Go 版本从 1.24.0 提升到 1.27.2。** 使用旧工具链的项目应先升级 Go，再升级本库。
- 既有公开 API 和 `/v6` 模块路径保持不变。
- 根模块继续只依赖标准库；PostgreSQL 相关依赖位于独立子模块。

## 新增 PostgreSQL 支持

- 新增 `github.com/weiweimhy/go-utils/postgres/v6`，使用 pgx v5.11.0 和 pgxpool。
- `NewPool(ctx, Config)` 解析连接配置、创建连接池并执行启动 Ping，成功后返回原生
  `*pgxpool.Pool`，由调用方负责关闭。
- 启动超时默认 10 秒；启动失败会清理已创建的池。后续查询使用调用方自己的上下文。
- 校验无效连接池配置，错误文本脱敏，并保留 `errors.Is`、`errors.As` 可检查的错误链。
- 提供生命周期测试、可编译示例和 PostgreSQL 18 实库集成测试。

使用说明见 [postgres/README.md](../../postgres/README.md)。

## 验证与 CI

- 本地使用 Go 1.27.2，通过全部 11 个模块的 vet 和测试。
- 根模块和 `postgres` 通过 race 检测；`postgres` 通过隔离 PostgreSQL 18 实例的集成测试。
- CI 新增 `postgres` 模块检查、race 检测和 PostgreSQL 18 服务集成测试。

## 安装

```bash
go get github.com/weiweimhy/go-utils/v6@v6.2.0
go get github.com/weiweimhy/go-utils/postgres/v6@v6.2.0
```

其他扩展模块可按需使用各自的 `/<子模块>/v6@v6.2.0` 路径安装。
