# 接口与数据边界

## 对外接口定位

本仓库导出 Go 包 API，不提供可供客户端调用的 HTTP 服务器。因此不存在仓库级的 Base
URL、路由、认证方案、请求体 schema 或数据库迁移协议。下游服务应自行定义其 HTTP、
RPC、身份认证和领域数据契约。

所有公开模块都使用含 `/v6` 的 Go module path。调用方只能依赖已导出的标识符；公开
函数的默认值、错误、资源关闭与并发语义属于兼容性契约。

## 网络边界

根模块的 `httputil` 是发起请求的客户端辅助包，不是 HTTP handler 层：

- 请求通过 `context.Context`、方法、URL、可选请求体和 `Options` 传入。
- 未指定时使用带超时的 HTTP 客户端，成功状态默认为任意 `2xx`。
- 成功响应默认最多读取 2 MiB。可通过 `MaxBytes` 调整限制，负数才会显式取消限制；超过限制
  返回 `ErrResponseTooLarge`，不会静默截断。
- 请求构造或传输失败返回可解包的 `RequestError`；非允许状态返回 `StatusError`。
- 返回错误中的 URL 会脱敏，包括用户信息、查询参数和 fragment 中的常见敏感键。错误响应体
  默认不保留，只有显式启用后才按上限捕获。

`wechat`、`tencentocr`、`mongo` 等子模块包装各自的第三方客户端或平台 API。调用方负责
其凭据、授权、业务重试与数据解释；库代码和测试不得将这些敏感值写入日志、错误或文档。

`download` 使用调用者提供的 `context.Context` 管理任务生命周期。每个下载默认限制为 1 GiB，
可用 `WithMaxBytes` 调整，负数显式取消限制；`Close` 会停止接收新任务、取消正在进行的请求并
等待已接收任务及其回调结束。若在回调中调用 `Close`，它只发起关闭而不会等待自身回调结束；
长时间忽略取消的任务会使其返回 `ErrCloseTimeout`。

`epub.OpenWithOptions` 默认将单个展开条目限制为 64 MiB、声明的展开总量限制为 512 MiB。
将相应限制设为负数才会显式取消限制。`Save` 在输出文件所在目录创建临时文件，完成 ZIP 写入并
关闭文件后再替换目标路径。

## 文件与本地数据

根模块的文件与 JSON 工具只处理调用方传入的路径和数据，不拥有业务数据模式：

- `fsutil` 提供普通与安全写入选项；安全写入使用原子写入及私有目录、文件权限。
- `pathutil` 用于约束相对路径和受控目录内的解析；调用方仍负责授权与检查-使用之间的
  文件系统竞争风险。
- `jsonutil` 提供严格解码边界，拒绝未知字段、重复对象键、尾随 JSON 值和超限输入。
- `jsonfile` 提供泛型 JSON 文件读取与写入；`localdb` 则是独立的 BBolt 子模块。

仓库没有统一数据存储、表结构或迁移目录。任何持久化格式、保留策略和事实来源均由使用
这些工具的下游项目定义。

## 进程内通信与生命周期

`event.Bus` 是本地进程内回调分发，不能当作跨进程消息队列。调用者需要保留并调用取消
订阅函数，并在不再使用时调用 `Close`。关闭后不再接受新的订阅或发布；已接收任务会在
工作 goroutine 退出前排空。使用方必须选择符合其背压、消息丢失和数据一致性需求的机制。
异步 handler 内调用 `Close` 只会发起关闭，以避免等待自身 dispatcher；外部调用仍会等待
已接收的任务排空。

`task`、`retry`、HTTP 与下载等可阻塞能力使用 `context.Context` 参与取消；纯内存小工具
不强制引入上下文。资源的创建方负责关闭其创建的客户端、文件或并发对象，并处理关闭时
返回的错误。`task.WorkerPool` 中的任务调用 `Close` 时也只会发起关闭并返回 `false`；外部
调用可等待完成并据返回值区分是否已正常关闭。
